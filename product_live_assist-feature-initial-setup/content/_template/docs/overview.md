# Getting started with YOUR PRODUCT

Replace this file with your real product documentation. Drop in as many .md/.txt files as you like —
help-center articles, feature guides, FAQs, pricing pages. Each becomes grounded knowledge Aidan can
cite, and it is what stops Aidan from inventing features.

Write plainly, one idea per paragraph. For example:

You create a report by opening the Reports tab and choosing a template. Reports refresh automatically
every morning, so the numbers are current when your team logs in.

Sharing a report gives teammates view-only access by default; you can grant edit access per person.
